# Use Cases

This folder contains short, practical examples of how AI can solve real business problems.  
Each use case includes:  
- The business problem  
- The AI-powered solution  
- Workflow impact  
- Example prompts  
- Potential ROI

---

## 📌 1. AI-Powered Meeting Summaries  
A GenAI assistant that transforms long meetings into actionable summaries.

**Business Problem:**  
Teams waste time manually pulling action items, risks, and decisions from meetings.

**AI Solution:**  
Use an LLM to generate:  
- Action items  
- Accountability assignments  
- Decisions made  
- Risks and blockers  
- Next steps  

**Workflow Impact:**  
Saves ~30–60 minutes per meeting.

**Example Prompt:**  
Summarize the meeting transcript into:

Key decisions

Assigned action items

Risks

Next steps
Use bullet points and assign owners.
